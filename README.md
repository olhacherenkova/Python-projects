# Python-projects

# Sales Analysis Report.
Created a Product and Sales Analytics dashboard (Python + Pandas + Matplotlib + Seaborn) that shows key KPIs, sales, costs, profit, top countries, product categories, delivery times, and seasonal sales trends.

# Calculation of statistical significance for A/B test results. 
Created an A/B Test Analytics dashboard (Python + Pandas + Statsmodels + Tableau) that calculates conversion rates, z‑tests, and p‑values, shows significant changes by test and device, and visualizes results with clear charts.

# User & Sales Analytics. 
Created a Sales and Traffic Analytics dashboard (SQL + Pandas + Tableau) that shows sales by devices and channels, average check, product categories, session trends, correlations, and statistical tests for user behavior.
